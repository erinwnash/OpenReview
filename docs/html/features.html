Domain 1: High-Performance Sequence & Video Playback Engine

Playback Engine & Media I/O
Multi-Format Image Sequence Ingestion
openreview/readers/
1. Purpose & Studio Context
High-end visual effects and animation pipelines operate primarily on uncompressed image sequences (OpenEXR, DPX, 16-bit TIFF) rather than compressed video files. OpenReview natively parses, indexes, and streams sequence directories without requiring intermediate transcodes.
2. UI Access & Hotkeys
Shortcut: Ctrl+O • Menu: File > Open Media... or drag-and-drop any sequence frame onto the viewport canvas or Sources Dock.
3. Step-by-Step Operator Guide
Press Ctrl+O or drag a frame into the viewport. OpenReview detects the frame padding pattern (e.g. sh010.####.exr), resolves the full continuous frame range (e.g. 1001–1100), mounts the sequence in the Sources Bin, and aligns the timeline transport automatically.
4. Technical Engine Mechanics
Managed by openreview/core/sequence_parser.py and format-specific readers. Tokenizes shot prefixes, padding widths, and extensions, validating sequence continuity asynchronously without locking the UI.
Supported Formats: OpenEXR, Cineon/DPX, 16-bit TIFF, PNG, JPEG Linked Screenshot: sources_session_dock.png
Containerized Video Playback Engine
openreview/readers/video_reader.py
1. Purpose & Studio Context
Editorial departments and client reviews frequently package daily cuts into Apple ProRes or Avid DNxHD QuickTime files. OpenReview provides hardware-accelerated video decoding alongside raw image sequences.
2. UI Access & Hotkeys
Shortcut: Ctrl+O • Drag-and-drop .mov or .mp4 containers onto the viewport.
3. Step-by-Step Operator Guide
Open any containerized video. The engine probes container streams, decodes video packets into linear RGB frames, extracts embedded audio, and presents frames smoothly with sub-frame timecode accuracy.
4. Technical Engine Mechanics
Built on FFmpeg and OpenCV streaming decoders. Frames are converted to RGBA float/uint8 textures and fed into the unified ring buffer cache.
Supported Codecs: ProRes (Proxy/422/4444), DNxHD/DNxHR, H.264, H.265 Linked Screenshot: timeline_transport_dock.png
Wall-Clock Real-Time Playback vs. Play Every Frame Mode
openreview/core/clock.py
1. Purpose & Studio Context
Checking dialogue lip-sync requires strictly maintaining wall-clock timing (Real-Time), while evaluating physics simulations, dynamic cloth, and FX particles requires viewing every calculated frame without skipping (Play Every Frame).
2. UI Access & Hotkeys
Toggle button in the Timeline Transport dock • Preferences dialog (Ctrl+,) > Playback.
3. Step-by-Step Operator Guide
Click the Real-Time toggle on the timeline bar. In Real-Time mode, the clock drops redundant display draws if storage bandwidth lags to maintain exact audio duration. In Play Every Frame mode, every single frame is guaranteed sequential presentation.
4. Technical Engine Mechanics
Managed in PlaybackClock using Python's high-resolution time.monotonic() timer. Frame presentation timestamps are evaluated on each tick with sub-millisecond precision.
Modes: Real-Time Sync (Wall-Clock) / Sequential Play-All-Frames Linked Screenshot: timeline_transport_dock.png
Non-Blocking Asynchronous Source Loading
openreview/core/async_source_loader.py
1. Purpose & Studio Context
When opening multi-gigabyte shot folders over high-latency network shares, the desktop interface must never freeze or become unresponsive.
2. UI Access & Hotkeys
Automatic background operation with status bar progress telemetry and cancellation support.
3. Step-by-Step Operator Guide
Drop a large shot directory into OpenReview. Canvas panning, zooming, and menus remain 100% interactive while worker threads validate headers and populate cache buffers in the background.
4. Technical Engine Mechanics
Thread-pool worker architecture with thread-safe Qt signals and task cancellation tokens in openreview/core/async_source_loader.py.
Architecture: Multi-threaded background prefetcher Linked Screenshot: status_bar.png

Timeline & Editorial Navigation
Multi-Speed JKL Transport Shuttling
openreview/ui/main_window.py

Industry-standard three-finger editorial shuttling allowing editors and VFX leads to navigate sequences without reaching for the mouse.
2. UI Access & Hotkeys
J: Shuttle Reverse (-1x, -2x, -4x, -8x) • K: Stop Playback • L: Shuttle Forward (+1x, +2x, +4x, +8x).
3. Step-by-Step Operator Guide
Tap L to play forward at 1x; tap again to accelerate to 2x, 4x, and 8x speed. Tap K to instantly halt on a frame. Tap J to shuttle in reverse at matching speed multiples.
4. Technical Engine Mechanics
Multiplies the clock's base target interval by the active shuttle coefficient and dynamically adjusts QMediaPlayer.setPlaybackRate() to preserve audio pitch/sync.
Speeds: -8x to +8x multi-step acceleration Linked Screenshot: timeline_transport_dock.png

Press Ctrl+T while scrubbing. The readout instantly toggles between absolute integer frame numbers (e.g. 1024) and SMPTE broadcast timecode (e.g. 01:00:04:23).
4. Technical Engine Mechanics
Computes drop-frame and non-drop-frame timecode math based on sequence start frame, current frame, and active project FPS.
Format: Standard SMPTE 12M broadcast timecode Linked Screenshot: timeline_transport_dock.png

Domain 3: Two-Tier Memory Caching (RAM Ring Buffer & Persistent Disk Cache)

Memory Management & Storage
Tier-1 RAM RingBufferCache with 80/20 Prefetching
openreview/core/cache.py
1. Purpose & Studio Context
Delivering smooth, stutter-free 60 FPS playback on uncompressed 4K float EXRs by keeping uncompressed frames cached in high-speed system RAM.
2. UI Access & Hotkeys
Configurable in *Preferences > Caching* (Ctrl+,) • Monitored via the green cached-frame indicator on the timeline.
3. Step-by-Step Operator Guide
Allocate a RAM cache budget (from 1.0 GB up to 64.0 GB). As you scrub or play, prefetch threads load 80% of budget ahead in playback direction and 20% behind the playhead for instant reverse shuttling.
4. Technical Engine Mechanics
Circular ring buffer tracking exact byte consumption, evicting the oldest unreferenced frames via LRU when the RAM limit is reached.
Capacity: Scalable 1.0 GB – 64.0 GB RAM Linked Screenshot: dialog_preferences_caching.png
Dedicated In/Out Region RAM Caching
openreview/ui/main_window.py
1. Purpose & Studio Context
Locking a specific 40-frame sequence segment into RAM so that a complex shot transition loops smoothly without disk access.
2. UI Access & Hotkeys
Shortcut: Shift+C • Menu: Playback > Cache In/Out Region.
3. Step-by-Step Operator Guide
Mark In ([) and Out (]) points around the review segment. Press Shift+C. The cache engine immediately loads that frame bracket into RAM, confirmed by a solid green timeline fill.
4. Technical Engine Mechanics
Pins the designated frame subset $[In, Out]$ with high priority, exempting those frames from normal LRU eviction while the region lock is active.
Feature: High-priority memory pinning Linked Screenshot: timeline_transport_dock.png
Tier-2 Persistent High-Speed Disk Caching
openreview/core/disk_cache.py
1. Purpose & Studio Context
Preserving decoded 32-bit float frames on fast local NVMe drives across application restarts to avoid repeating slow network decompression.
2. UI Access & Hotkeys
Configurable in *Preferences > Caching* (Ctrl+,).
3. Step-by-Step Operator Guide
Enable Persistent Disk Cache in Preferences and specify a directory path. Previously viewed frames load near-instantaneously from NVMe storage upon reopening the sequence.
4. Technical Engine Mechanics
Binary block serialization with fast LZ4/Zstandard compression, keyed by sequence filepath hash, frame index, and file modification timestamp.
Storage: Local NVMe cache directory Linked Screenshot: dialog_preferences_caching.png

Scene-Linear Exposure (EV) & Linear Gain
openreview/color/shader_builder.py
1. Purpose & Studio Context
Checking highlight details or underexposed shadows in 32-bit floating-point HDR media using photographic F-stop stops.
2. UI Access & Hotkeys
Alt++ / Alt+-: Exposure (±0.25 EV) • + / -: Linear Gain • E: Reset Exposure • Ctrl+Alt+R: Reset All.
3. Step-by-Step Operator Guide
Press Alt++ to stop up exposure into highlights, or Alt+- to stop down into dark shadows. Press E to return exposure to default 0.0 EV.
4. Technical Engine Mechanics
Calculated in GLSL fragment shader: color.rgb = color.rgb * uGain * exp2(uExposureEV);.
Range: -10.0 to +10.0 F-stop stops (EV) Linked Screenshot: hud_color_adjustments.png
Instant Display Invert Colors
openreview/color/shader_builder.py
1. Purpose & Studio Context
Inverting displayed colors allows rotoscope artists and compositors to inspect matte halos, fringing, and hair edge continuity against complementary backgrounds.
2. UI Access & Hotkeys
Shortcut: Shift+I • Checkbox in Color Adjustments HUD (/).
3. Step-by-Step Operator Guide
Press Shift+I while reviewing an edge or matte seam. The display inverts instantly. Dark edges against light backgrounds stand out with high contrast. Press again to revert.
4. Technical Engine Mechanics
Evaluated at the output stage of the GLSL fragment shader: if (uInvert) rgb = vec3(1.0) - rgb;.
Operation: Non-destructive display-space inversion Linked Screenshot: hud_color_adjustments.png

Difference & Inverted Difference Modes with 20x Amplification
openreview/color/shader_builder.py
1. Purpose & Studio Context
Confirming zero unintended pixel alterations outside roto mattes and exposing sub-perceptual render deviations.
2. UI Access & Hotkeys
Access: Mode dropdown in Wipe Controller HUD (select *Difference* or *Difference Inverted*).
3. Step-by-Step Operator Guide
Switch to Difference mode. Matching pixels render pure black. Increase the Diff Boost slider (up to 20x) to reveal minute differences. Switch to Inverted Difference to render matching pixels solid white and discrepancies in deep black.
4. Technical Engine Mechanics
Computes abs(colorA - colorB) * uDiffBoost and 1.0 - abs(colorA - colorB) * uDiffBoost in the fragment shader.
Amplification: 1.0x to 20.0x gain multiplier Linked Screenshot: hud_wipe_controller.png
