Complete Features & Keyboard Shortcuts Guide

This manual documents every single capability in OpenReview—both foundational studio features and newly introduced enhancements—followed by the complete, searchable 78+ action RV / Nuke / 3DEqualizer hybrid keyboard shortcut registry.

1. Playback Engine, JKL Shuttling & Timecode

🎬 Real-Time vs. Play All Frames

Switch seamlessly between Wall-Clock Real-Time Sync (drops frames if disk I/O lags to maintain exact audio/timecode duration) and Play Every Frame (guarantees every single frame is displayed sequentially for VFX simulation QC).

⏩ JKL Multi-Speed Shuttling

Tap L repeatedly to accelerate forward playback through 1x, 2x, 4x, and 8x. Tap K to halt immediately. Tap J repeatedly to shuttle in reverse at -1x, -2x, -4x, and -8x.

🔁 Three Loop Modes

Cycle playback boundary behavior on the timeline: Loop (wrap around continuously), Ping-Pong (bounce forward and backward seamlessly across the In/Out range), and Play Once (halt automatically on the last frame).

⏱️ SMPTE Timecode & Go-To Frame

Toggle timeline readouts between integer Frame Numbers (e.g. 1024) and SMPTE Timecode (01:00:00:23) with Ctrl+T. Press Ctrl+G to open the frameless Go-To Frame HUD with auto-range clamping.

  • Interactive Canvas Scrubbing: When the Canvas Scrub mode icon is active in the Top Control Bar, dragging horizontally with the Left Mouse Button anywhere on the viewport scrubs smoothly across frames—ideal for rapid back-and-forth edge inspection.
  • Timeline Magnifier Mini-Ruler (Shift+T): Toggles a high-precision zoomed scrub strip above the main timeline so you can step frame-by-frame even inside 10,000-frame master reels.
  • In/Out Range Clamping & Bookmark Segments: Set custom playback brackets with [ (Mark In) and ] (Mark Out), clear individually with Alt+I / Alt+O, or clear both with \. Press PageDown / PageUp to step the active In/Out loop bracket across consecutive bookmarked segments or sequence clips.

2. Asynchronous RAM Caching & Hardware GPU Acceleration

  • Four RAM Cache Modes:
    1. Cache Off: Direct on-demand disk streaming without background prefetching.
    2. Play-Ahead Cache: Dynamically caches a moving window around the playhead (80% ahead in the current playback direction, 20% behind).
    3. In/Out Region Cache (Shift+C): Dedicates the worker thread pool to caching every frame inside the marked [In .. Out] range.
    4. Cache All: Prefetches the entire clip or multi-clip sequence up to the configured RAM ceiling (1 GB – 64 GB).
  • Granular Cache Flushing & Disk Reloading:
    • Reload Current Frame (Ctrl+R): Evicts only the current frame from RAM and re-reads it from disk (ideal when re-rendering a single bad frame in Nuke).
    • Reload Active Sequence (Ctrl+Shift+R): Flushes cached frames for the active source and re-scans the directory for newly rendered frames.
    • Clear RAM Cache (Ctrl+Shift+C) & Clear All Sources Cache (Ctrl+Delete): Instantly frees memory across active or all loaded bins.
  • Three GPU Playback Engines: Switch dynamically in Preferences → GPU Acceleration (or by clicking the GPU badge in the bottom status bar) between OpenGL 3.3 Core, Async PBO DMA Streaming (double-buffered zero-stall GPU transfers), and Software Safe Mode.

3. Color Science, Dynamic GLSL Grading, LUT/CDL & OCIO v2

  • Scene-Linear Exposure (EV) & Gain: Adjust linear gain (+ / - in ±0.10 steps) or photographic F-stop Exposure (Alt++ / Alt+- in ±0.25 EV steps). Reset instantly with Ctrl+Alt+E or E.
  • Display Gamma & Luma-Preserving Saturation: Step Gamma by ±0.05 with Shift++ / Shift+- (reset with Ctrl+Alt+G) and Saturation by ±0.05 with Ctrl+Shift++ / Ctrl+Shift+-.
  • Invert Colors (Shift+I): Instantly inverts display-space RGB channels (1.0 - RGB) in the GLSL fragment shader—essential for judging subtle black-level grain, Flare/Matte holes, and high-contrast rotoscoping edges.
  • Interactive Color Adjustments Panel (/): Provides master and per-channel (Red, Green, Blue) sliders for Exposure, Gain, Offset, Gamma, Contrast (around 18% grey pivot), Saturation, Hue rotation (-180° to +180°), and Display Brightness. Reset all color adjustments with Ctrl+Alt+R or Shift+Home.
  • 3D / 1D LUT & ASC CDL Pipeline: Load industry-standard .cube and .3dl LUTs into hardware 3D texture memory, and load .cdl, .cc, or .ccc ASC CDL grades. Toggle LUT and CDL bypass independently from the Color → LUT / CDL menu.
  • Out-of-Range (OOR) Zebra Clipping Overlay: Highlights super-white values (> 1.0) in Magenta and negative values (< 0.0) in Cyan.
  • Single-Key Channel Isolation: Isolate Full RGB (C), Red (R), Green (G), Blue (B), Alpha (A), or Rec.709 Luminance (Y).

4. A/B Split Wipes, Difference Modes, Multi-Layer Stacks & Tiled Layouts

  • Interactive Split Wipe (W): Drag the wipe line directly in the viewport to translate split position or drag near the handle to rotate the split angle through 360°. Press Shift+W to flip orientation between vertical and horizontal, or Alt+W to reset position to 50% and angle to 0°.
  • Six Composite View Types: Available under Review → View Type and in the Stack HUD:
    • Replace (Single): Standard single-source view.
    • Sequence: Back-to-back editorial cut playback.
    • Over (Alpha Composite): Premultiplied foreground Slot A over background Slot B (A + B * (1 - alpha_A)).
    • Add: Additive blending (A + B) for light-pass reconstruction.
    • Difference: Absolute pixel difference |A - B| * DiffBoost (matching pixels appear pure black).
    • Difference (Inverted): Solarized white-background difference 1.0 - |A - B| * DiffBoost so 1-pixel dust busts or grain changes pop clearly against white.
  • Stack Layer Cycling (Z / Shift+Z): Step forward and backward through stacked render layers or shot takes while locked on the exact same frame and zoom coordinates.
  • Multi-Tile Contact Sheet Layouts: View 2 to 16+ sources simultaneously in Auto Grid, Side-by-Side, Over/Under, 2x2, or 3x3 layouts with real-time synchronized playback and interactive tile reordering.

5. Viewport Geometry, Theatrical Mattes, Safe Guides & Presentation Mode

  • Flop, Flip, Rotation & Pixel Aspect Ratio (PAR): Mirror horizontally (Shift+X) to check composition balance with fresh eyes, flip vertically (Shift+Y), rotate in 90° increments, and preview anamorphic squeeze factors (2:1 Anamorphic, NTSC, PAL, Square 1.0).
  • Bilinear vs. Nearest-Neighbor Filtering (N): Switch between smooth bilinear interpolation and sharp nearest-neighbor pixel blocks when zoomed in to 400%/800% for sub-pixel edge and grain analysis.
  • Theatrical Aspect Ratio Mattes (Ctrl+M / Shift+M): Cycle through 1.33:1, 1.66:1, 1.77:1, 1.85:1, 2.35:1, and 2.40:1 crop overlays and cycle mask opacity (25%, 35%, 50%, 100%).
  • Broadcast Safe Guides (Shift+G): Toggle 90% Action Safe, 80% Title Safe, Center Crosshair, and Rule of Thirds 3x3 Grid with optional constraint to the active theatrical matte.
  • Borderless Fullscreen (F12) & Presentation Mode (Ctrl+P): Fullscreen preserves Windows DWM popup compositing so floating HUDs and context menus never flicker over OpenGL. Presentation Mode hides all menus, toolbars, timelines, and docks for distraction-free director/client screening.

6. 32-Bit Floating-Point Pixel Probe, Area Samplers & Live Histogram

  • Real-Time Cursor Readout: Bottom status bar and Color Inspector HUD (F5) report scene-linear 32-bit float RGBA, 8-bit integer RGB, HSV, Hex, and Rec.709 Luminance (Y) under the cursor.
  • Pinned Point & Area Box Samplers: Click in Eyedropper mode to pin persistent crosshairs or drag rectangular sample regions on the canvas. Computes live Minimum, Maximum, and Average (Mean) RGBA across the sampled region.
  • Corrupted Pixel Alerts (NaN / Inf / Neg): Automatically counts and flags NaN, Infinity, and negative pixel values inside the active frame or sampled box.

7. Resolution-Independent Vector Annotations & Review Notes

  • Six Vector Drawing Tools: Freehand Pen (D), Straight Line, Directional Arrow, Rectangle Box, Circle/Ellipse, and Direct In-Canvas Text Editor.
  • Normalized Coordinate Storage: Strokes are stored in normalized [0.0 .. 1.0] image space so drawings remain locked to exact image features regardless of window resizing, zoom, pan, or proxy resolution changes.
  • Per-Frame Undo/Redo & Keyframe Stepping: Independent Undo (Ctrl+Z) and Redo (Ctrl+Shift+Z / Ctrl+Y) stacks per frame. Jump between annotated keyframes using . (Next) and , (Previous).
  • Annotation Manager (Ctrl+Shift+A): Inspect all annotated frames, attach multi-line text notes per frame, and export/import review packages in JSON, CSV, or Markdown.

8. Pipeline Version Stepping & Session Management

  • Automatic Version Detection (Alt+Up / Alt+Down): Parses version tokens (v001, v002, _v03) in file and folder paths, scanning disk to step up or down to the next available render iteration while preserving playhead frame, zoom/pan, and In/Out marks.
  • Complete Session Persistence (.ovr): Save (Ctrl+S), Save As (Ctrl+Shift+S), Open (Ctrl+Shift+O), New Session (Ctrl+N), and Close / Clear Session (Ctrl+Shift+N).

9. Multi-Channel EXR AOV Passes & Stereoscopic 3D

  • EXR Layer Switcher: Inspect beauty, diffuse, specular, emission, Z-depth, and cryptomatte passes from multi-part OpenEXR files.
  • Stereo 3D Review: Left Eye, Right Eye, Anaglyph (Red-Cyan), Side-by-Side Split, and Stereo Difference modes with interactive horizontal pixel convergence offset.

10. Sub-Frame Audio Sync & Multi-User Remote Dailies

  • Audio Scrubbing & Offset Calibration: 60ms scrubbing audio bursts on timeline/canvas drag, 45ms drift auto-resync, and independent Seconds + Frames offset controls.
  • Remote Dailies Sync (Ctrl+Shift+D): Host or join TCP review rooms with Presenter lock, Follow toggle, live stroke/grade broadcasting, and integrated room chat.

11. Media Export, Python SDK & Plugin Manager

  • Burn-In Media Exporter (Ctrl+Shift+E): Export sequences, In/Out ranges, Bookmarked frames, or Annotated keyframes to .mov, PNG sequence, JPEG sequence, or single PNG with burned-in vector annotations and grading.
  • JSON-RPC 2.0 IPC Server & Plugin Architecture: Full remote control from Nuke, Maya, and Houdini on port 45124 and custom Python plugins via PackageManager.
