Python SDK, DCC Integration & Custom Plugin Developer Guide

OpenReview provides two complementary extensibility APIs for pipeline technical directors (TDs) and studio software engineers:

  1. External IPC Python SDK (openreview.sdk): Zero-dependency Python client communicating over TCP JSON-RPC 2.0 (`127.0.0.1:45124`) to remotely control OpenReview from Foundry Nuke, Autodesk Maya, SideFX Houdini, Blender, ShotGrid daemons, or farm scripts.
  2. In-Process Plugin & Package Engine (openreview.packages): Full lifecycle event hook system (`OpenReviewPlugin` & `PluginContext`) with direct access to the live `MainWindow`, `ViewportCanvas`, `PlaybackClock`, `AnnotationStore`, and `SessionGraph`.

1. JSON-RPC 2.0 IPC Architecture & Wire Protocol

When OpenReview starts, IpcServer (network/ipc_server.py) binds an asynchronous QTcpServer on 127.0.0.1:45124. External tools send newline-delimited UTF-8 JSON-RPC 2.0 payloads and receive synchronous JSON responses: 

// Outgoing TCP Request (terminated by '\n')
{"jsonrpc": "2.0", "id": 1, "method": "load_media", "params": {"path": "/shows/vfx/sh010/comp/v004/sh010_comp_v004.1001.exr"}}

// Incoming TCP Response (terminated by '\n')
{"jsonrpc": "2.0", "id": 1, "result": {"status": "loaded", "path": "/shows/vfx/sh010/comp/v004/sh010_comp_v004.1001.exr"}}

// Querying Complete Viewer & Session State
{"jsonrpc": "2.0", "id": 2, "method": "get_status", "params": {}}
// Response:
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "media_path": "/shows/vfx/sh010/comp/v004/sh010_comp_v004.1001.exr",
    "media_type": "sequence",
    "current_frame": 1024,
    "start_frame": 1001,
    "end_frame": 1080,
    "in_frame": 1010,
    "out_frame": 1065,
    "fps": 24.0,
    "is_playing": true,
    "loop_mode": "loop",
    "exposure_ev": 0.5,
    "gain": 1.414,
    "gamma": 1.0,
    "saturation": 1.0,
    "channel_mode": 0,
    "playback_engine": "opengl_core",
    "bookmarks": [1015, 1032, 1050]
  }
}

2. OpenReviewClient Python SDK Reference

The OpenReviewClient class (src/openreview/sdk/client.py) uses only Python's standard library (socket, json)—meaning it can be imported inside any DCC's embedded Python interpreter (Python 3.7–3.12+) without installing PySide6 or NumPy.

2.1 Developer Quickstart Example

from openreview.sdk.client import OpenReviewClient, OpenReviewError
from openreview.sdk.dcc import review_in_openreview

# Option A: One-liner helper (auto-launches OpenReview if not already running)
review_in_openreview(
    media_path="/shows/vfx/seq010/sh010/renders/sh010_comp_v004.1001.exr",
    in_frame=1001,
    out_frame=1080,
)

# Option B: Full programmatic control via OpenReviewClient
client = OpenReviewClient(host="127.0.0.1", port=45124, timeout=4.0)

if client.ping():
    # 1. Load EXR sequence or QuickTime movie
    client.load_media("/shows/vfx/seq010/sh010/renders/sh010_comp_v004.1001.exr")

    # 2. Configure frame rate, In/Out range, and bookmarks
    client.set_fps(24.0)
    client.set_in_out(1009, 1072)
    client.clear_bookmarks()
    client.add_bookmark(1024)
    client.add_bookmark(1048)

    # 3. Apply non-destructive GLSL color grading
    client.set_color(exposure=0.25, gain=1.189, gamma=1.05, saturation=1.10)

    # 4. Seek to hero frame, export a PNG snapshot, and start playback
    client.seek(1024)
    client.export_frame("/tmp/sh010_hero_frame_1024.png")
    client.play()

    # 5. Inspect live telemetry
    state = client.get_status()
    print(f"Playing {state['media_path']} at {state['fps']} FPS (Frame {state['current_frame']})")

2.2 Complete OpenReviewClient Method Reference

SDK Method Signature RPC Method Return Type Description
ping() ping bool Returns True if an OpenReview instance is listening on the target host/port.
get_status() get_status Dict[str, Any] Returns complete dictionary of active media path, frame range, playhead, FPS, color grade, and bookmarks.
load_media(path: str) load_media bool Loads a video file, image sequence, still image, audio file, or .ovr session into OpenReview.
play() play bool Starts sequence playback and returns True.
pause() pause bool Pauses active playback and returns True.
toggle_play() toggle_play bool Toggles play/pause state and returns the new is_playing boolean.
seek(frame: int) seek int Jumps playhead to the specified frame number and returns the clamped frame.
set_fps(fps: float) set_fps float Sets the playback clock frame rate (e.g., 24.0, 30.0, 60.0).
set_in_out(in_frame: int, out_frame: int) set_in_out Dict[str, int] Clamps timeline loop In and Out points to [in_frame, out_frame].
set_exposure(ev: float) set_color float Sets viewer F-stop exposure compensation in EV stops.
set_gain(gain: float) set_color float Sets viewer linear exposure gain multiplier.
set_gamma(gamma: float) set_color float Sets viewer display gamma power curve.
set_saturation(sat: float) set_color float Sets viewer Rec.709 luma-preserving saturation multiplier.
set_color(gain, gamma, saturation, exposure) set_color Dict[str, float] Atomically updates multiple viewer color parameters in a single RPC call.
add_bookmark(frame: Optional[int], note: str) add_bookmark List[int] Adds a bookmark at frame (or current frame if None) and returns sorted bookmark list.
clear_bookmarks() clear_bookmarks List[int] Clears all timeline bookmarks.
export_current_frame(destination: str) / export_frame(destination, frame) export_frame str / bool Captures the current OpenGL viewport buffer and saves it to destination image path.

3. Developer-Ready DCC Integration Guides & Scripts

Built-in DCC helpers are provided in src/openreview/sdk/dcc.py. Below are complete, copy-paste-ready studio deployment scripts for Foundry Nuke, Autodesk Maya, SideFX Houdini, and Blender.

3.1 Foundry Nuke Integration (~/.nuke/menu.py)

Registers a Pipeline → Send Read/Write to OpenReview command bound to Ctrl+Alt+R, plus an automatic afterRender callback that pushes completed Nuke Write renders straight into OpenReview: 

# ~/.nuke/menu.py — Foundry Nuke Studio Integration for OpenReview
import nuke
from openreview.sdk.dcc import review_in_openreview
from openreview.sdk.client import OpenReviewClient

def send_selected_to_openreview():
    """Send selected Nuke Read or Write node to OpenReview with exact frame range and FPS."""
    nodes = nuke.selectedNodes()
    if not nodes:
        nuke.message("Please select a Read or Write node first.")
        return

    node = nodes[0]
    if node.Class() not in ("Read", "Write"):
        nuke.message(f"Node '{node.name()}' ({node.Class()}) is not a Read or Write node.")
        return

    file_path = nuke.filename(node, nuke.REPLACE)
    first = int(node["first"].value()) if "first" in node.knobs() else int(nuke.root()["first_frame"].value())
    last = int(node["last"].value()) if "last" in node.knobs() else int(nuke.root()["last_frame"].value())
    fps = float(nuke.root()["fps"].value())

    review_in_openreview(file_path, in_frame=first, out_frame=last)
    client = OpenReviewClient()
    if client.ping():
        client.set_fps(fps)

def auto_review_after_write_render():
    """Optional Write node afterRender callback."""
    node = nuke.thisNode()
    if node and node.Class() == "Write":
        file_path = nuke.filename(node, nuke.REPLACE)
        first = int(nuke.root()["first_frame"].value())
        last = int(nuke.root()["last_frame"].value())
        review_in_openreview(file_path, in_frame=first, out_frame=last)

# Register top menu item & shortcut
pipeline_menu = nuke.menu("Nuke").addMenu("OpenReview")
pipeline_menu.addCommand("Review Selected Node in OpenReview", send_selected_to_openreview, "Ctrl+Alt+R")

3.2 Autodesk Maya Shelf & Playblast Hook

Captures a viewport 2.0 H.264 / ProRes playblast matching the Maya timeline range and frame rate, then streams it immediately into OpenReview: 

# Maya Shelf Button Script — Playblast Directly to OpenReview
import os
import tempfile
import maya.cmds as cmds
from openreview.sdk.dcc import review_in_openreview
from openreview.sdk.client import OpenReviewClient

def maya_playblast_to_openreview():
    start_f = int(cmds.playbackOptions(q=True, min=True))
    end_f = int(cmds.playbackOptions(q=True, max=True))

    scene_name = cmds.file(q=True, sn=True, shn=True) or "untitled_maya_scene"
    base_name = os.path.splitext(scene_name)[0]
    out_file = os.path.join(tempfile.gettempdir(), f"{base_name}_playblast.mov")

    pb_path = cmds.playblast(
        filename=out_file,
        format="qt",
        compression="H.264",
        quality=100,
        percent=100,
        widthHeight=(1920, 1080),
        showOrnaments=True,
        forceOverwrite=True,
        viewer=False,
    )
    if pb_path:
        review_in_openreview(pb_path, in_frame=1, out_frame=(end_f - start_f + 1))

maya_playblast_to_openreview()

3.3 SideFX Houdini Solaris / Karma / Mantra Post-Render Hook

Add this script to the Post-Render Script parameter on any Mantra, Karma, or OpenGL ROP node in Houdini: 

# SideFX Houdini ROP Post-Render Script (Python)
import hou
from openreview.sdk.dcc import review_in_openreview
from openreview.sdk.client import OpenReviewClient

rop = hou.pwd()
# Resolve output picture parm across Mantra (vm_picture), Karma (picture), or Fetch/OpenGL (picture)
for parm_name in ("vm_picture", "picture", "lopoutput"):
    parm = rop.parm(parm_name)
    if parm is not None:
        out_path = parm.evalAtFrame(hou.frame())
        start_f = int(rop.parm("f1").eval()) if rop.parm("f1") else int(hou.playbar.frameRange()[0])
        end_f = int(rop.parm("f2").eval()) if rop.parm("f2") else int(hou.playbar.frameRange()[1])
        review_in_openreview(out_path, in_frame=start_f, out_frame=end_f)
        break

4. OpenReview Package & Plugin Extension Architecture

OpenReview features a first-class plugin engine managed by PackageManager (src/openreview/packages/package_manager.py). Plugins are self-contained folders (or installable .zip packages) discovered automatically from three locations in priority order:

  1. Built-in Packages: src/openreview/packages/builtin/
  2. User Packages Directory: ~/.openreview/packages/
  3. Studio Environment Variable: Any directories listed in $OPENREVIEW_PACKAGE_PATH (separated by ; on Windows or : on Linux/macOS).

4.1 Package Directory Structure & manifest.json Specification

Every plugin folder contains a manifest.json (or package.json) metadata file and a Python entrypoint module (default plugin.py):

~/.openreview/packages/my_studio_plugin/
├── manifest.json
└── plugin.py
{
  "id": "com.studio.shotgrid_sync",
  "name": "ShotGrid Review Sync",
  "version": "1.2.0",
  "author": "Maruthu Chakravarthi / Studio Pipeline Team",
  "description": "Synchronizes OpenReview annotations, frame notes, and approval statuses with ShotGrid.",
  "entrypoint": "plugin.py",
  "min_openreview_version": "1.0.0",
  "enabled": true,
  "category": "Pipeline Integration",
  "tags": ["shotgrid", "dailies", "notes", "publish"],
  "hooks": ["on_media_loaded", "on_annotation_added", "on_session_saved"]
}

4.2 OpenReviewPlugin Base Class & Lifecycle Hooks

Your plugin.py defines a subclass of OpenReviewPlugin (openreview.packages.plugin_base). Each plugin instance receives a self.context (PluginContext) providing self.context.main_window, self.context.log(msg), and self.context.show_toast(msg):

Hook Method Signature When Fired
initialize() / on_init(context) (self) -> None Called immediately when the plugin is loaded on startup or enabled in the Package Manager. Ideal for adding custom menu items to self.context.main_window.menuBar().
shutdown() / on_shutdown() (self) -> None Called when the plugin is disabled, unloaded, or when OpenReview exits. Clean up threads or sockets here.
on_media_loaded(media_path) (self, media_path: str) -> None Fired whenever a new video, image sequence, or still is loaded into the viewer.
on_frame_changed(frame) (self, frame: int) -> None Fired on every playhead frame change or timeline scrub.
on_playback_state_changed(is_playing) (self, is_playing: bool) -> None Fired whenever playback starts or pauses.
on_annotation_added(annotation) (self, annotation: Stroke) -> None Fired whenever a user finishes drawing a vector stroke or text callout on the canvas.
on_session_saved(session_path) (self, session_path: str) -> None Fired after an OpenReview .ovr session file is written to disk.
on_session_loaded(session_path) (self, session_path: str) -> None Fired after an OpenReview .ovr session file is opened.

5. Custom Studio Plugin Recommendations with Production Code Examples

Below are four complete, production-ready custom plugin implementations designed for VFX and animation studios. Each example can be dropped directly into ~/.openreview/packages/<plugin_name>/plugin.py alongside a manifest.json.

5.1 Recommendation 1: ShotGrid / Ftrack / Kitsu Note & Status Publisher Plugin

Use Case: During supervisory dailies, the supervisor draws vector annotations on key frames and types notes in the Annotation Manager. Clicking Studio → Publish Review Notes to ShotGrid automatically renders burned-in JPEG attachments for every annotated frame and uploads them with frame numbers and supervisor comments to your production tracking database. 

"""
~/.openreview/packages/shotgrid_publisher/plugin.py
Publishes annotated keyframes, burned-in attachments, and supervisor notes to ShotGrid / Kitsu.
"""
import os
import re
import tempfile
from pathlib import Path
from openreview.packages.plugin_base import OpenReviewPlugin
from openreview.core.exporter import MediaExporter


class ShotGridPublisherPlugin(OpenReviewPlugin):
    """Studio production tracking publisher extension for OpenReview."""

    def initialize(self) -> None:
        self.context.log("Initializing ShotGrid Review Publisher Plugin...")
        win = self.context.main_window
        if win and hasattr(win, "menuBar"):
            studio_menu = win.menuBar().addMenu("&Studio Pipeline")
            pub_act = studio_menu.addAction("Publish Annotated Frames & Notes to ShotGrid...")
            pub_act.triggered.connect(self.publish_current_session_notes)

    def _parse_shot_and_version(self, media_path: str) -> tuple[str, str]:
        """Extract shot code (e.g. sh010) and version (e.g. v004) from pipeline path."""
        name = Path(media_path).name
        shot_match = re.search(r"(sh\d+|seq\d+_sh\d+)", name, re.IGNORECASE)
        ver_match = re.search(r"(v\d{2,4})", name, re.IGNORECASE)
        return (
            shot_match.group(1) if shot_match else "unknown_shot",
            ver_match.group(1) if ver_match else "v001",
        )

    def publish_current_session_notes(self) -> None:
        win = self.context.main_window
        if not win:
            return

        media_path = getattr(win, "_current_media_path", None) or ""
        shot_code, version_code = self._parse_shot_and_version(media_path)
        annot_frames = win.annotation_store.get_annotated_frames()

        if not annot_frames:
            self.context.show_toast("No annotated frames or notes to publish.")
            return

        out_dir = Path(tempfile.gettempdir()) / "openreview_sg_publish" / f"{shot_code}_{version_code}"
        out_dir.mkdir(parents=True, exist_ok=True)

        published_payloads = []
        for frame_num in annot_frames:
            # Render native frame with burned-in vector strokes and active grade
            rgb_img = win._render_frame_for_export(frame_num)
            jpg_path = out_dir / f"{shot_code}_{version_code}.{frame_num:04d}.jpg"
            MediaExporter.save_image_file(rgb_img, str(jpg_path))

            note_text = win.annotation_store.get_frame_note(frame_num) or "See burned-in frame annotation."
            published_payloads.append({
                "shot": shot_code,
                "version": version_code,
                "frame": frame_num,
                "note": note_text,
                "attachment": str(jpg_path),
            })

        # Here you would call sg.create("Note", ...) via shotgun_api3 or gazu (Kitsu)
        self.context.log(f"Published {len(published_payloads)} annotated frames for {shot_code} ({version_code}) to {out_dir}")
        self.context.show_toast(f"Published {len(published_payloads)} notes for {shot_code} {version_code}!")

5.2 Recommendation 2: Automated Technical QC & NaN/Inf/Framerate Validator Plugin

Use Case: Automatically validates every sequence loaded into OpenReview against studio delivery specs (checking for 24.0 FPS compliance, ACEScg colorspace, missing/dropped frame gaps on disk, and corrupted NaN / Inf / negative pixels on the start frame) and alerts the artist immediately with a viewport toast and console report. 

"""
~/.openreview/packages/auto_qc_validator/plugin.py
Automated Technical Quality Control (QC) Validator on Media Load.
"""
import numpy as np
from openreview.packages.plugin_base import OpenReviewPlugin
from openreview.core.sequence_parser import detect_image_sequence


class AutoQCValidatorPlugin(OpenReviewPlugin):
    """Runs automatic studio technical QC checks whenever media is loaded."""

    REQUIRED_FPS = 24.0
    EXPECTED_RESOLUTION = (1920, 1080)

    def initialize(self) -> None:
        self.context.log("Automated Technical QC Validator Plugin active.")

    def on_media_loaded(self, media_path: str) -> None:
        win = self.context.main_window
        if not win:
            return

        issues = []

        # 1. Check Sequence Frame Continuity (Missing / Dropped Frames)
        seq = detect_image_sequence(media_path)
        if seq and len(seq.available_frames) > 1:
            expected_set = set(range(seq.start_frame, seq.end_frame + 1))
            missing = sorted(list(expected_set - set(seq.available_frames)))
            if missing:
                issues.append(f"Missing {len(missing)} frames (e.g. {missing[:5]})")

        # 2. Check Frame Rate Compliance
        if abs(win.clock.fps - self.REQUIRED_FPS) > 0.01:
            issues.append(f"FPS mismatch ({win.clock.fps} FPS vs studio {self.REQUIRED_FPS} FPS)")

        # 3. Check First Frame for NaN / Inf Pixels and Resolution
        img = getattr(win.viewport, "_image_a", None)
        if img is not None and isinstance(img, np.ndarray):
            h, w = img.shape[:2]
            if (w, h) != self.EXPECTED_RESOLUTION:
                issues.append(f"Non-standard resolution: {w}x{h}")
            nan_count = int(np.isnan(img).sum())
            inf_count = int(np.isinf(img).sum())
            if nan_count > 0 or inf_count > 0:
                issues.append(f"CRITICAL: {nan_count} NaN and {inf_count} Inf pixels detected!")

        if issues:
            summary = " | ".join(issues)
            self.context.log(f"[QC WARNING] {media_path}: {summary}")
            self.context.show_toast(f"QC Warning: {issues[0]}", duration_ms=5000)
        else:
            self.context.log(f"[QC PASSED] {media_path} conforms to all studio specifications.")
            self.context.show_toast("QC Passed: Sequence conforms to studio specs.")

5.3 Recommendation 3: Custom Studio Telemetry & Artist Burn-In HUD Plugin

Use Case: Extends the built-in TimecodeHudPlugin pattern to dynamically update the viewport's top Info Strip Overlay (Ctrl+I) on every frame with studio-specific shot telemetry (Show Code, Artist Name, Department, SMPTE Timecode, and Focal Length). 

"""
~/.openreview/packages/studio_hud_burnin/plugin.py
Populates the Viewport Info Strip with live Studio Shot Telemetry on every frame.
"""
import os
from pathlib import Path
from openreview.packages.plugin_base import OpenReviewPlugin
from openreview.core.timecode import frame_to_timecode


class StudioBurnInHudPlugin(OpenReviewPlugin):
    """Dynamic studio metadata burn-in HUD extension."""

    def initialize(self) -> None:
        self.show_code = os.environ.get("SHOW_CODE", "VFX_FEATURE_2026")
        self.artist_name = os.environ.get("USERNAME", os.environ.get("USER", "artist"))
        self.context.log(f"Studio Burn-In HUD initialized for show: {self.show_code}")

    def on_media_loaded(self, media_path: str) -> None:
        win = self.context.main_window
        if win and hasattr(win, "viewport"):
            win.viewport.set_show_info_strip(True)
            self._refresh_hud(win.clock.current_frame)

    def on_frame_changed(self, frame: int) -> None:
        self._refresh_hud(frame)

    def _refresh_hud(self, frame: int) -> None:
        win = self.context.main_window
        if not win or not hasattr(win, "viewport"):
            return

        fps = win.clock.fps
        tc = frame_to_timecode(frame, fps)
        media_name = Path(getattr(win, "_current_media_path", None) or "No Media").name

        win.viewport.update_info_strip_data(
            show=self.show_code,
            shot=media_name,
            artist=self.artist_name,
            frame=frame,
            timecode=tc,
            fps=f"{fps:.2f}",
            colorspace=win.ocio_manager.input_space or "ACEScg",
        )

5.4 Recommendation 4: Client Review HTML Contact Sheet & Note Report Generator

Use Case: Automatically generates a self-contained, styled HTML review report with embedded base64/PNG thumbnails of every annotated keyframe, timecode stamps, stroke counts, and supervisor notes whenever a session is saved (or via menu command)—ready to email or upload to confluence/client portals. 

"""
~/.openreview/packages/html_review_exporter/plugin.py
Generates a formatted HTML Client Review Contact Sheet with annotated frame thumbnails.
"""
import base64
from io import BytesIO
from pathlib import Path
from openreview.packages.plugin_base import OpenReviewPlugin
from openreview.core.timecode import frame_to_timecode


class HtmlReviewReportPlugin(OpenReviewPlugin):
    """Exports an HTML visual contact sheet whenever a session with annotations is saved."""

    def on_session_saved(self, session_path: str) -> None:
        win = self.context.main_window
        if not win:
            return

        annot_frames = win.annotation_store.get_annotated_frames()
        if not annot_frames:
            return

        report_path = Path(session_path).with_suffix(".review_report.html")
        rows_html = []

        for frame_num in annot_frames:
            tc = frame_to_timecode(frame_num, win.clock.fps)
            note = win.annotation_store.get_frame_note(frame_num) or "(Vector markup only)"
            strokes = win.annotation_store.get_strokes(frame_num)

            # Save frame thumbnail alongside HTML report
            thumb_name = f"{Path(session_path).stem}_frame_{frame_num:04d}.png"
            thumb_path = report_path.parent / thumb_name
            rgb_arr = win._render_frame_for_export(frame_num)
            from openreview.core.exporter import MediaExporter
            MediaExporter.save_image_file(rgb_arr, str(thumb_path))

            rows_html.append(f"""
            <div style="display:flex; gap:20px; background:#1c1e22; border:1px solid #333; border-radius:8px; padding:16px; margin-bottom:16px;">
              <img src="{thumb_name}" style="width:360px; border-radius:4px; border:1px solid #444;" />
              <div>
                <h3 style="color:#e5a823; margin:0 0 8px 0;">Frame {frame_num} &bull; Timecode {tc}</h3>
                <p style="color:#9ca3af; font-size:13px;">Vector Strokes: {len(strokes)}</p>
                <p style="color:#e6edf3; font-size:15px;">{note}</p>
              </div>
            </div>
            """)

        html_doc = f"""<!DOCTYPE html>
<html><body style="background:#121315; color:#e6edf3; font-family:sans-serif; padding:32px;">
  <h1 style="color:#e5a823;">OpenReview Dailies Report — {Path(session_path).stem}</h1>
  {''.join(rows_html)}
</body></html>"""

        report_path.write_text(html_doc, encoding="utf-8")
        self.context.log(f"Exported HTML Review Contact Sheet to {report_path}")
        self.context.show_toast(f"Saved HTML Review Report: {report_path.name}")
